# CODSOFT Data Science Internship — Task 1

## Titanic Survival Prediction

### Project Overview
This project uses Machine Learning to predict whether a passenger survived the Titanic disaster.

### Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier

### Project Workflow
1. Load and explore the Titanic dataset.
2. Handle missing values.
3. Prepare numerical and categorical features.
4. Train a Random Forest classification model.
5. Evaluate model performance using accuracy and a classification report.
6. Predict survival for passengers in the test dataset.

### How to Run
Install the required libraries:

`python -m pip install pandas numpy scikit-learn`

Keep `train.csv`, `test.csv`, and `Titanic_prediction.py` in the same folder.

Run the project:

`python Titanic_prediction.py`

### Output
The program displays model accuracy and a classification report. Predictions are saved to `submission.csv`.
